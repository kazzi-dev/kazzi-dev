## ⭐ Featured: [Papeles](https://github.com/kazzi-dev/papeles)

**Know exactly what to bring before you line up.** Ask what you need for SSS, PhilHealth,
Pag-IBIG, PSA, NBI or LTO papers in English, Tagalog or Bisaya, and get a checklist and next
steps backed by official agency sources, with citations.
**[▶ Try it live](https://papeles-tau.vercel.app)**

<a href="https://github.com/kazzi-dev/papeles">
  <img src="https://raw.githubusercontent.com/kazzi-dev/papeles/main/docs/screenshots/answer-lto.png" width="420" alt="Papeles answering how much an LTO student permit costs, with cited official facts">
</a>

- **RAG pipeline:** official pages and PDFs → chunking → multilingual embeddings → pgvector search
  → LLM answer that cites every fact
- **Honest by design:** cited official facts are kept apart from general guidance, which is
  clearly labeled "please verify"
- **Runs on free tools:** Groq, Gemini or OpenRouter free tiers (or Claude), switchable from `.env`
- **Stack:** Next.js · TypeScript · FastAPI · PostgreSQL + pgvector · Docker · GitHub Actions ·
  pytest

## ⭐ Featured: [TrabaHub](https://github.com/kazzi-dev/trabahub)

**Every job you're chasing, in one place.** A job-application tracker: drag openings from
*Saved* to *Applied*, *Interview* and *Offer*, and get a follow-up reminder a week after you apply.
Career coaches can invite job seekers and follow their progress.
**[▶ Try it live](https://trabahub-six.vercel.app)** (one-click demo, no sign-up) ·
**[API docs](https://trabahub-api.onrender.com/docs)**

- **Typed full stack:** one set of Zod schemas shared by the Express API, the Next.js app and
  the OpenAPI docs
- **Teams with roles:** owner, admin, coach and member permissions, enforced on the API and
  mirrored in the UI
- **Production habits:** GitHub/Google OAuth, rate limiting, SQL migrations, 34 API tests, a
  Docker image, Terraform for the hosting, and CI on every push
- **Stack:** Next.js · React · TypeScript · Node.js + Express · PostgreSQL (Neon) · Drizzle ORM ·
  Docker · Terraform · GitHub Actions · Vitest
